# Przemyśl Tour – Etap 14, wersja 1.4.1

Poprawiona paczka modułu WCAG, mobile, wydajności i Google Maps dla wtyczki Przemyśl Tour – Wyścigi i Trasy 1.3.0+.

## Instalacja

1. Pobierz archiwum gałęzi `przemysl-tour-stage14`.
2. W WordPress przejdź do **Wtyczki → Dodaj wtyczkę → Wyślij wtyczkę na serwer**.
3. Wgraj pobrany ZIP bez dodatkowego przepakowywania.
4. Aktywuj **Przemyśl Tour – Etap 14 WCAG i wydajność**.
5. Otwórz **Przemyśl Tour → WCAG i wydajność**.

Główny plik PHP znajduje się bezpośrednio w katalogu głównym archiwum, dlatego WordPress rozpoznaje paczkę jako prawidłową wtyczkę.

## Google Maps

Panel zawiera bezpośrednie odnośniki do:

- utworzenia projektu Google Cloud,
- Google Maps Platform,
- włączenia Maps JavaScript API,
- utworzenia klucza API,
- utworzenia Map ID,
- konfiguracji rozliczeń,
- limitów i wykorzystania API.

Klucz należy ograniczyć do domeny serwisu przez **Websites / HTTP referrers** oraz do **Maps JavaScript API**.
